# 🏦 Loan Approval Prediction

## 📌 Project Overview

Loan Approval Prediction is a Machine Learning project that predicts whether a loan application is likely to be **Approved** or **Rejected** based on applicant information.

The project includes data preprocessing, exploratory analysis, multiple machine learning models, hyperparameter tuning, model evaluation, and a Streamlit web application for making predictions.

---

## 🎯 Objective

The main objective of this project is to build a machine learning model that can predict loan approval based on factors such as:

* Applicant income
* Coapplicant income
* Credit history
* Education
* Marital status
* Number of dependents
* Loan amount
* Loan term
* Property area
* Employment status
* Gender

## 🤖 Models Used

The following machine learning algorithms were tested:

1. Logistic Regression
2. Decision Tree
3. Random Forest

Random Forest was then further tuned using `GridSearchCV`.

---

## ⚙️ Hyperparameter Tuning

`GridSearchCV` was used to find better Random Forest parameters.

The best parameters found were:

```text
n_estimators = 300
max_depth = 10
min_samples_split = 2
min_samples_leaf = 1
```

The best cross-validation score was approximately **80.85%**.

The final tuned Random Forest achieved approximately **78.05% accuracy** on the test set.

## 🌐 Streamlit Application

The project includes a Streamlit application where users can enter applicant information and receive a loan approval prediction.

The application accepts information such as:

* Gender
* Married status
* Dependents
* Education
* Self-employment status
* Applicant income
* Coapplicant income
* Loan amount
* Loan term
* Credit history
* Property area

The application then uses the trained Random Forest model to generate a prediction.

## ▶️ How to Run the Project

```bash

```

### 2. Open the project folder

```bash
cd Loan_Approval_Predictor
```

### 3. Install the required libraries

```bash

```

### 4. Run the Streamlit application

```bash
python -m streamlit run app.py
```

## 📌 Prediction Output

The application provides one of two predictions:

```text
✅ Loan Approved
```

or

```text
❌ Loan Rejected
```

The prediction is generated by the trained machine learning model and should not be treated as a guarantee of an actual lending decision.
